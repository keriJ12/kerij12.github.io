02 · Tools

小工具

解決一個特定問題的小型實用工具：輸入什麼、得到什麼、為誰省下什麼步驟。

Tools 01 · 樣品部門

布樣標註工具

到貨的布樣照片，需要附上清楚的資訊才能交接。標註日期與物流商，再把整理好的圖片直接複製進郵件。

加入照片 → 標註資訊 → 分享
開啟工具 ↗說明頁
Tools 02 · 洗標製作

洗標符號組合器

製作一張洗標，應該是件簡單的事。排列洗滌符號、設定實體尺寸，就能匯出可放進文件或設計稿的標籤圖片。

選擇符號 → 設定尺寸 → 匯出
開啟工具 ↗說明頁
Tools 03 · 語言學習

Parola · 義大利文練習

短時間練習義大利文，也讓每次答錯成為複習的起點。從快速挑戰接到重點複習，幫助德語使用者重新練習容易卡住的單字與文法。

開始練習 → 複習錯題 → 再試一次
開啟工具 ↗說明頁
Tools 04 · 生產備料

紗線需求計算器

把客戶訂單換算成紗線需求，需要串起多份檔案裡的資訊。這個工具比對訂單明細、品項與紗線資料，計算所需用量，並標出缺漏資訊供人工核對。

比對訂單資料 → 計算用量 → 核對
開啟工具 ↗說明頁

布樣標註、洗標與紗線計算源自紡織工作的實際需求。工具介面依作品提供中文或德文，說明頁另有英文版。

把抽籤、打電話、敲餅乾和寄託心事，變成螢幕上的小儀式。試試聲音、等待與動作，能帶來什麼感受。

關於我

我習慣從實際工作現場的問題出發：先弄清楚資訊在誰手上斷掉、哪些判斷必須由人負責，再決定流程怎麼設計、AI 放在哪裡才可被核對。作品以可操作的原型驗證想法，並寫明做到哪、哪裡只是模擬。

目前的作品都是本機概念原型，沒有企業導入成效；下一步是讓陌生使用者實際操作，看流程是否清楚。
