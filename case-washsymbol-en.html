Care-Label Composer — pick the symbols, export a label at the right physical size

A single-file tool for the colleague responsible for care labels (Pflegekennzeichnung) at an Austrian textile company: choose washing, bleaching, ironing, professional care and drying symbols in the standard order, preview the label strip live, export JPEG or PNG at a given size in centimetres with the dpi written into the file. Paste it into Word or Illustrator and it is already the right size — no rescaling.

01Context

The setting

Every new item needs a care label — repetitive work with little tolerance for error

Care symbols follow an international standard and a customary order, and the company has its own set of frequent combinations. The old way: pick symbol files by hand, drag them into Word, resize and align one by one. Sizes drifted, the order was occasionally wrong, and the printed size did not always match. The person making labels is not a designer and should not need to be.

Environment

Company PC, a browser, no installs allowed

The user double-clicks a local HTML file on a company computer. No server, nothing can be installed. That constraint decided the form: one file, offline-capable, every symbol image embedded.

02Problem

Problem statement

The slow part of manual assembly is “the exported size is wrong”

It looks right on screen, but pasted into layout software it has to be rescaled again, and rescaling risks blur. The real problem was not “assemble symbols faster” but “the exported file must open at the correct physical size”. Once stated that way, the core of the tool reduced to one thing: think in centimetres and write the dpi into the file.

03Design decisions

Decision · Core

Centimetres as the frame; dpi written into JPEG and PNG

The user types “6 × 1.5 cm”, not pixels. The tool computes the canvas from centimetres and dpi, fits the symbol block as large and centred as possible, and on export writes the dpi into the JPEG JFIF header or the PNG pHYs chunk. Word, Illustrator and InDesign open it at 6 × 1.5 cm. “Correct on open” is what actually removed the manual work.

Decision · Order

Whatever the click order, output follows the standard order

Washing → bleaching → ironing → professional care → drying is the customary order on care labels. Taking that order out of human memory removes one class of error.

Decision · Presets

Nine out of ten labels are a rotation of a few fixed combinations

Nine one-click presets use “no bleach, P dry-clean, no tumble dry” as the base and vary only washing and ironing temperature, each suggesting a filename. Apply, then fine-tune — faster than starting from zero, and nothing gets forgotten.

Decision · Colours

Three colour schemes, no free colour picker

White on black, black on white, white on navy — matching common label fabrics. Care labels are usually printed in one colour; a free picker invites colours that cannot be printed. Technically one set of black symbols is tinted on the canvas, so one image set serves every scheme.

Decision · Languages

Every symbol carries German, English and Traditional Chinese from the start

The company sells into German-speaking markets, but some orders and supply-chain documents need English or Chinese. The legend and the optional in-image captions share one data source, so the three languages never disagree.

04Technical notes

Hand-written parts

Two pieces of byte-level work without a library

  • JPEG dpi: read the exported blob, verify the APP0 marker and JFIF signature, rewrite the density unit and X/Y density bytes directly.
  • PNG dpi: convert dpi to pixels per metre, build a pHYs chunk, compute CRC32, insert it after the PNG signature and IHDR.
  • Layout: measure the symbol block with captions at unit size, compute the scale that fits “canvas minus margins”, re-lay-out and centre; each symbol has a relative-height correction for visual balance.
  • Tolerance: size fields accept German decimal commas; saved settings are checked against existing symbol ids so stale data cannot break the app.
Form

One HTML file of about 1 MB, 97% of it embedded symbols

32 symbol PNGs are inlined as base64; the program itself is about 30 KB. The cost is file size; the gain is “one file that opens anywhere”. Settings persist in the browser so the next session continues with the same size, dpi and colours.

05Limits

Limits

It solves one company's job, not care labelling in general

The UI is German; only in-image captions are trilingual. The symbol set is the 32 the company needed, not the full standard. Symbols are always one row or column — overflow shrinks the whole block rather than wrapping. Chinese captions fall back to the operating system's font and vary slightly between machines. The portfolio version removes the company name and internal preset names; functionality is unchanged.

Why it is here

It shows that stating the problem correctly beats adding features

Had the requirement been “a faster symbol assembly tool”, the result would have been a prettier assembly tool. Because the problem was stated as “exports must open at the right size”, the genuinely time-saving feature — writing dpi into the file — came into existence.
